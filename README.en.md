# Lüji (律迹)

![Lüji icon](luji-icon.svg)

**An offline Android app for private personal activity records and trends.** This public repository hosts APK releases, release notes, documentation, and feedback. It does not contain the app source code, signing key, or anyone's records.

Install the APK through Android's system installer. To upgrade, install the newer APK over the existing app; **do not uninstall the old app or clear its data first**. The package ID and signing identity are retained so a compatible upgrade preserves local records. You can also choose GitHub in **Settings → Updates** inside the app, then check, download, and install an available update.

## What the app does

- Per-user period tracking, continuous pain controls, historical entries, cycle analysis and date predictions. Predictions cannot confirm ovulation or determine contraceptive safety.
- Calendar based entries, editing, and trend charts.
- Real time motion estimates from the phone's sensors, with a frequency curve and manual count correction.
- TXT / XLSX import and export, plus a full text backup with motion history.
- Separate local users, color themes, and Chinese / English UI.

Motion estimates describe movement of the **phone**, not a medical or fitness measurement. Exported files are unencrypted. See the [Chinese usage guide](USAGE.md), [release history](CHANGELOG.md), and [privacy notes](PRIVACY.md).
